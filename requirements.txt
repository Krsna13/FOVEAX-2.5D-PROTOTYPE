# CRITICAL HARDWARE NOTE:
# The development target is an NVIDIA RTX 5050 Laptop GPU (Blackwell
# GB207, compute capability sm_120). The default `pip install torch`
# resolves to a cu126 build. That build INSTALLS SUCCESSFULLY and
# reports `torch.cuda.is_available() == True`, but has NO compiled
# sm_120 kernels -- it will fail on any real GPU tensor operation with
# "CUDA error: no kernel image is available for execution on the
# device". This is silent until you actually run inference; it will
# not show up as an install-time error.
#
# Install the cu130 build explicitly instead:
#   pip install torch==2.14.0 torchvision --index-url https://download.pytorch.org/whl/cu130
#
# (torchvision has no separate +cu130-suffixed release on PyPI/the
# PyTorch index at this version; installing it from the cu130 index
# alongside the pinned torch build above resolves it to the matching
# build automatically -- confirmed in this project's real environment
# as torchvision==0.29.0+cu130.)
--extra-index-url https://download.pytorch.org/whl/cu130
torch==2.14.0+cu130
torchvision==0.29.0+cu130
